ComplaintCAPaylaşım Paneli

GitHub ile bağlan

Panel, paylaşım takvimini GitHub'daki social/queue.json dosyasından okur ve oraya yazar. Bunun için bir kez GitHub anahtarı (token) girmen gerekiyor. Anahtar sadece bu tarayıcıda saklanır, hiçbir yere gönderilmez.

  1. Yeni token oluştur (Fine-grained)
  2. Repository access → Only select repositories → ComplaintCa
  3. Permissions → Contents: Read and write, Actions: Read and write, Secrets: Read-only
  4. Oluşan token'ı aşağıya yapıştır
