# Dias Ajan (Chrome eklentisi)

Dias Panel > Claude sekmesinden verdiğin işi senin Chrome'unda yapar:
resmi formu açar, bilgilerinle doldurur, **Gönder'e basmaz** (onu sen yaparsın).
Şifre, kart ve SIN alanlarına dokunmaz. Bilmediği bilgiyi sorar.

## Kurulum (bir kere)
1. Bu klasörü (`extension/`) bilgisayara indir, zip ise aç.
2. Chrome'da `chrome://extensions` aç, sağ üstten **Geliştirici modu**nu aç.
3. **Paketlenmemiş öğe yükle** > bu klasörü seç.
4. `complaintca.ca/dias-claude.html` sayfasını yenile: "🤖 Tarayıcıda yap" butonu çıkar.

## Kullanım
Örnek: `Rogers internetim 3 gündür yok, CCTS'ye şikayet formunu doldur. Adım ..., hesap no ...`
Link yazarsan oradan başlar, yazmazsan resmi sayfayı kendi bulur.
Soru sorarsa cevabı aynı kutuya yaz. Durdurmak için "Ajanı durdur".
